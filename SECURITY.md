# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential PII data disclosure issue within this repository:

1. **Do NOT open a public GitHub issue.**
2. Send an email to security@datakaveri.org detailing the vulnerability and steps to reproduce.
3. High-severity alerts and vulnerabilities are patched within one week of disclosure.
